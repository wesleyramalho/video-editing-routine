# video-editing-routine

Automatically removes filler words (`eh`, `hmm`, `um`...) and long pauses from Portuguese audio and video using Whisper. The audio script renders a clean MP3. The video script outputs an OpenShot project and an FCPXML so you can fine-tune each cut in your editor before exporting.

## Requirements

- macOS (tested); Linux should work with minor tweaks
- `ffmpeg` + `ffprobe`
- Python 3.9+
- ~500 MB of disk for the Whisper `small` model (auto-downloaded on first run)

## Setup

```bash
chmod +x setup.sh
./setup.sh
```

This installs Homebrew (if missing), `ffmpeg`, and the `openai-whisper` Python package.

## Usage — Audio

```bash
python3 clean_audio.py input.mp3
```

Produces `input_clean.mp3` in the same folder. Sample log:

```
      1976 words transcribed
      64 fillers detected
      36 long silences detected
      original duration: 750.6s
      final duration:    646.5s
      savings:           104.1s (13.9%)
```

## Usage — Video

```bash
python3 clean_video.py input.mp4
```

Produces three files:

| File | Purpose |
|---|---|
| `input_cuts.osp` | OpenShot project — `File > Open Project` |
| `input_cuts.fcpxml` | FCPXML — imports in DaVinci Resolve, Final Cut Pro |
| `input_cuts.json` | Fallback — list of `{position, source_start, source_end, duration}` segments |

The original MP4 is **not** modified. Every "keep" segment becomes an individual clip on the timeline — drag the borders to fine-tune cuts before exporting the final video.

### Captions (optional)

```bash
python3 clean_video.py input.mp4 --captions
```

`--captions` generates `input_cuts.srt` with word timestamps mapped to the NEW cut timeline (so filler words that were cut don't appear in the captions). Groups 3-5 words per line, up to ~2s each. Import the SRT into your editor — OpenShot, DaVinci, FCP and most players default to centered-bottom positioning.

## How to open the outputs

- **OpenShot**: `File > Open Project…` → pick the `.osp`. Clips appear stacked on Track 4.
- **DaVinci Resolve** (free): `File > Import > Timeline…` → pick the `.fcpxml`. If it asks to relink media, point to the original MP4.
- **Final Cut Pro**: `File > Import > XML…` → pick the `.fcpxml`.
- **iMovie**: not supported. iMovie's FCPXML import is restricted to XML generated by Final Cut Pro. Use DaVinci Resolve instead.

## How it works

1. **Transcribe**: Whisper (OpenAI, local) produces per-word timestamps at sub-second accuracy for Portuguese audio
2. **Detect**: a configurable list of filler tokens + any pause longer than a threshold are flagged as cuts
3. **Invert**: the inverse (segments to KEEP) is computed — overlapping cuts are merged, a small buffer preserves natural breaths
4. **Emit**:
   - `clean_audio.py` → `ffmpeg` with `filter_complex` + `atrim` + `concat` renders a single clean MP3
   - `clean_video.py` → generates a JSON project for OpenShot and FCPXML for every other editor; the original video is never re-encoded

## Flags reference

| Flag | Default | Meaning |
|---|---|---|
| `--model` | `base` (audio) / `small` (video) | Whisper size. `tiny` → `large`. Larger = slower + more accurate |
| `--silence` | `0.8` | Seconds of silence above which to cut. Lower = more aggressive |
| `--pad` | `0.1` | Safety margin (seconds) around each filler to avoid clipping real words |
| `--captions` | off | Video only. Emits a `.srt` subtitle file aligned to the cut timeline |

## Language

Whisper is pinned to `language="pt"` (Portuguese). The filler word list in `clean_audio.py` (`PT_FILLER_WORDS`) targets Portuguese fillers. Fork the constant and the `language=` argument to adapt to another language.
